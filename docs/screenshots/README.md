# Screenshots

Add screenshots here before submitting.

## Capture guidance

- Use a clean browser window with no devtools open.
- Capture at desktop width, ideally 1440x900 or 1920x1080.
- Use the Vancouver to Calgary demo data.
- Avoid showing API keys, tokens, browser profile details, or private notifications.
- If a hosted demo is available, add the URL to `SUBMISSION.md`.

## Suggested files

1. `01-quote-form.png` - app loaded with the quote form visible
2. `02-generated-quote-result.png` - generated quote range, confidence, and customer-ready response
3. `03-messy-request-parser.png` - parser output and the `From parser: N fields` confirmation chip
4. `04-quote-history.png` - recent quote history panel after generating at least one quote

If time is tight, include at least:

1. A generated quote result screenshot
